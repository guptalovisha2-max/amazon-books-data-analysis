
# Amazon Books Data Analysis

## About This Project
This is my Python data analysis project using sample book data.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Features
- Read book data from a CSV file
- Calculate average book price
- Find the highest-rated book
- Compare book prices using a bar chart
- Compare book ratings using a bar chart

## Files
- amazon.py
- books.csv
- README.md

## How to Run
Install the libraries:
pip install pandas matplotlib

Run the project:
python amazon.py

## Note
This project uses sample data for learning purposes.
